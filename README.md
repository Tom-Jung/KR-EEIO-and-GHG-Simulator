# 🌿 KE_EEIO (GHG Only)
**한국은행 환경산업연관분석 — 온실가스 배출 Scope 분석 모델**
 
---
 
## Ⅰ. 개요
 
**EEIO(Environmentally Extended Input-Output)** 는 온실가스 및 에너지 등의 관련 통계를 국민계정 통계의 하나인 산업연관표와 결합하여, 거시경제 내 개별 산업의 온실가스 배출량을 **Scope 1 · 2 · 3** 로 정교하게 분리하고 할당(Allocation)하는 분석 체계
 
- 인벤토리 총량을 기초 배출량(Scope 1)으로 고정하고, 생산유발계수를 통해 **전력 사용에 따른 간접 배출(Scope 2)** 과 **원재료 사용 등에 따른 간접 배출(Scope 3)** 을 수학적으로 도출
- **불변가격 산업연관표**를 편제하여 가격효과를 제거함으로써 각 산업의 배출계수 등의 **시계열 비교**를 가능하게 함
- 정교한 분석이 어려운 중소기업 등을 위해 회사 업종, 매출액, 주요 원재료 등의 제한된 자료만으로 탄소배출량을 간략히 계산할 수 있는 **Simulator** 를 함께 개발

## Ⅲ. 편제 방법
 
### 1. 산업별 온실가스 배출량
 
온실가스 인벤토리를 기반으로 하되, 인벤토리 항목이 여러 산업에 해당하거나 명확하지 않을 경우 에너지 밸런스와 산업연관표의 배분 자료를 이용합니다.
 
> 📄 자세한 내용은 **국민계정리뷰(2025년 1월), '대기배출계정 시산 결과'** 참조
 
### 2. 불변 산업연관표
 
- 경상 산업연관표에 물가지수를 적용하여 편제하며 **이중디플레이션(Double-Deflation)** 방법을 이용
- 국산과 수입을 구분하며, 아래 지수를 활용
  `PPI` · `CPI` · `GDP 디플레이터` · `수출입물가` · `환율` · `서비스물가(IMF)`

## Ⅳ. EEIO 모델 개요
 
### 핵심 개념
 
| 개념 | 설명 |
|------|------|
| **투입산출표 (IO Table)** | 산업 간 재화·서비스 거래 구조를 행렬로 표현한 국가 통계 |
| **레온티에프 역행렬 L** | 최종 수요 1단위 증가 시 각 산업에 파급되는 총생산 유발량 |
| **직접배출계수 B** | 산업 *i* 가 1백만 원 생산 시 직접 발생시키는 온실가스 (kt CO₂eq) |
| **공급망 유발계수 B×L** | 최종 수요 1백만 원 발생 시 공급망 전체에서 유발되는 총 온실가스 |
 
### 핵심 수식
 
$$A = Z \div X \quad \text{(투입계수 행렬)}$$
 
$$L = (I - A)^{-1} \quad \text{(레온티에프 역행렬)}$$
 
$$B = E \div X \quad \text{(직접 환경 계수)}$$
 
$$\text{총 유발계수} = B \cdot L$$
 
> $Z$: 중간재 거래 행렬 (33×33) &nbsp;|&nbsp; $X$: 총산출액 벡터 (33×1) &nbsp;|&nbsp; $E$: 직접 온실가스 벡터
 
### ⚠️ 전력 부문 Scope 2 이중계산 보정
 
| 구분 | 내용 |
|------|------|
| **문제** | 전력산업의 소내소비전력 특성상 M[D,D]에 Scope 1이 중복 포함됨 |
| **해결** | 전력산업에 한해 `Scope2[D] = M[D,D] − B[D]` 로 보정 |

## Ⅵ. 구성 항목
 
경상가격과 불변가격으로 각각 편제되며, 구성 항목은 다음과 같습니다.
 
| 항목 | 변수명 | 설명 |
|------|--------|------|
| 총거래표 | `T_mat_GHG` | 산업연관표(수입+국산) 및 산업별 배출량 |
| 투입(배출)계수 | `Ad` | 산출액 단위당(백만원) 배출량 |
| 생산유발계수 | `Lf` | 특정 품목에 대한 최종수요(백만원)가 유발하는 전산업 생산액|
| 배출유발계수 | `M` | 특정 품목에 대한 최종수요(백만원)가 유발하는 전산업 배출량|
| 최종수요 항목별 배출액 | `M·fd` | 각 최종수요 항목이 유발하는 총 배출량  |
| 생산액기준 배출액 | `M·X(diag)` | 특정 품목의 생산액이 유발하는 전산업 배출량 |
| 배출 범위 | `Scopes 1, 2, 3` | 직·간접 배출 구분 |
| 수입거래표 | `I_mat` | 산업연관표(수입) |
| 국산거래표 | `D_mat` | 산업연관표(국산) |
